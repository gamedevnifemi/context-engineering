# References

Official documentation consulted for the statements this repository makes about how Claude Code
behaves. Retrieved 2026-09-11. Where a page and this repository disagree, the page wins and the
repository needs a fix.

| Topic | Page | Facts taken |
|---|---|---|
| Context window and compaction | [Explore the context window](https://code.claude.com/docs/en/context-window) | The "What survives compaction" table: the system prompt still applies; project-root CLAUDE.md, unscoped rules, auto memory and the plan written in plan mode are re-injected from disk; up to five recently read or edited files are re-read, and a file over 5,000 tokens comes back as a path reference; invoked skill bodies are re-injected, capped at 5,000 tokens each and 25,000 in total; context that hooks added earlier is summarised with the rest; `SessionStart` hooks matching `compact` run and their output is added. `/compact` with a focus, `/rewind` "Summarize from here" and "Summarize up to here", `/autocompact` to compact earlier. |
| How Claude Code works | [How Claude Code works](https://code.claude.com/docs/en/how-claude-code-works) | "It clears older tool outputs first, then summarizes the conversation if needed. Your requests and key code snippets are preserved; detailed instructions from early in the conversation may be lost." Transcripts are JSONL under `~/.claude/projects/`. Resuming appends to the same session id; forking copies the history into a new id. Auto-compaction stops with an error rather than looping when context refills immediately. |
| Model configuration | [Model configuration](https://code.claude.com/docs/en/model-config) | Models with a native 1M window "compact before the window fills, at about 967K tokens by default"; `/autocompact`, `--autocompact` and `CLAUDE_CODE_AUTO_COMPACT_WINDOW` change that. Effort levels `low` to `max`; `high` is the default on most models; `max` "may show diminishing returns and is prone to overthinking". The `[1m]` suffix selects the 1M window. |
| Sessions | [Manage sessions](https://code.claude.com/docs/en/sessions) | Transcript path and the 30-day `cleanupPeriodDays` retention. "The entry format is internal to Claude Code and changes between versions, so scripts that parse these files directly can break on any release." Resume-from-summary dialog on Pro and Max plans after about an hour idle over 100k tokens: it runs `/compact`, keeps the summary, the most recent exchanges and up to five recently read files, and "whatever the summary leaves out is no longer in Claude's context". `SessionEnd` hooks receive `transcript_path`; `/export` renders a transcript. |
| Memory | [How Claude remembers your project](https://code.claude.com/docs/en/memory) | CLAUDE.md content "is delivered as a user message after the system prompt". Project-root CLAUDE.md survives compaction because it is re-read from disk; instructions given only in conversation do not. A "Compact instructions" section in CLAUDE.md steers the summary. Auto memory lives under the project's transcript directory and is excluded from the retention sweep. |
| Hooks reference | [Hooks reference](https://code.claude.com/docs/en/hooks) | Events include `PreCompact` (matcher `manual` or `auto`), `PostCompact`, `SessionStart` (matchers `startup`, `resume`, `clear`, `compact`, `fork`) whose plain-text stdout is added as context, `SessionEnd`, `PreModelSwitch`, `PostModelSwitch` and `InstructionsLoaded`. |
| Costs | [Manage costs effectively](https://code.claude.com/docs/en/costs) | Compaction and tool-result clearing count as expected rebuilds of the prompt cache. "`/compact` reads the conversation it summarizes, so compacting a large context is itself a large request." `/context` shows what consumes space. Keep CLAUDE.md under about 200 lines. Subagents keep verbose output out of the main context. |
| Best practices | [Best practices](https://code.claude.com/docs/en/best-practices) | "LLM performance degrades as context fills." Auto compaction "summarizes what matters most, including code patterns, file states, and key decisions"; CLAUDE.md can say what to preserve. After two failed corrections, `/clear` and start with a better prompt. `/btw` answers stay out of history. |
| Settings | [Settings](https://code.claude.com/docs/en/settings) | `CLAUDE_CONFIG_DIR` moves settings, session history and plugins off `~/.claude`. |
